Formula hunt

Pi's digits look random, but pi has exact formulas. Each hunt evaluates a family of continued fractions a(0) + b(1)/(a(1) + b(2)/(a(2) + …)) with polynomial a(n), b(n), matches each limit against simple expressions in π, and re-checks every match at 600-bit precision. The same search against a random constant is the control: it must stay at zero.

"Distinct" means different after removing three trivial changes: starting the same fraction a few terms later (n → n + k), rescaling (a → c·a, b → c²·b), and polynomial "dressing" (a → c(n)·a, b → c(n)c(n−1)·b). Each row is one such core; "variants" counts the fractions that reduce to it. Rows can still be equivalent through deeper transformations, and "classical" marks only the few formulas in PiLens's own short list, so an unmarked row is not a claim of novelty. The OEIS column comes from pilens novelty: it looks up the core's numerator and denominator sequences at oeis.org. "known" means a matching entry mentions the constant; "sequence in OEIS" means the sequence is catalogued but the entry does not mention the constant; "not in OEIS" means neither sequence is catalogued. That makes the identity a candidate, not proof that it is new.
